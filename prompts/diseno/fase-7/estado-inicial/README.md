# Estado inicial del producto

Capturas reales del frontend local, tomadas antes del CSS del bloque 3 de Fase 7
el 16 de noviembre de 2026. No son imágenes de la maqueta.

Chrome temporal: viewport CSS de 1440 × 900 o 390 × 900 px, escala 1,
preferencia de color clara. Las imágenes incluyen el contenido completo, por
eso su altura puede superar 900 px. El ancho de 390 comprueba composición
estrecha; no reproduce el hardware ni todos los comportamientos táctiles de un móvil.

Se inició sesión desde el formulario con las dos cuentas de prueba autorizadas.
El selector de espacio confirmó owner y miembro en la misma familia. Solo se
consultaron vistas: no se crearon suscripciones, invitaciones ni pagos y no se
marcaron avisos como leídos. Las sesiones se cerraron después de utilizarlas.
No se introdujo ningún código de invitación ni se capturaron contraseñas.
